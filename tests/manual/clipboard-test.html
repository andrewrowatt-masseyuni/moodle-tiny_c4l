Expected Behavior

  • Cut: When cursor is in a component, it should be removed and stored in clipboard
  • Copy: When cursor is in a component, it should be copied to clipboard (original remains)
  • Paste: Component from clipboard should be inserted at cursor position
  • Nested: Cursor in inner component selects only inner; cursor in outer (not inner) selects all
